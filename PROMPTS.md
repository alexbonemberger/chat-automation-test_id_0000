# Prompts de transporte

1. Já executado. No repositório alexbonemberger/chat-automation-test_id_0000, grave em responses/0001.txt na main uma resposta em UTF-8 identificada por CHAT_GIT_OK_0001. Confirme lendo o arquivo no commit publicado.
2. Com o listener aberto, envie ao chat com acesso de escrita ao GitHub o parágrafo abaixo.

No repositório alexbonemberger/chat-automation-test_id_0000, branch main, crie responses/0002.txt. Na primeira linha escreva CHAT_GIT_OK_0002. Na segunda, escreva em português uma frase escolhida por você agora. Se o arquivo já existir, preserve-o. Leia o arquivo no commit publicado e informe o SHA e a frase.

3. Para outro turno, use o mesmo prompt com o próximo número sequencial de quatro dígitos no caminho e no marcador. O listener exibe as respostas como texto, consulta a main a cada oito segundos e reapresenta o histórico ao iniciar.
